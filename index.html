Stet Flatpak repository

Stet 1.7.0, the text and code editor, as a Flatpak for Linux distributions other than Omarchy and Arch. On Omarchy, install the Arch package instead: see INSTALL.md.

Install it, and the GNOME runtime it needs from Flathub, with one line:

flatpak install --user https://github.com/PixDevsApps/Stet/releases/latest/download/io.github.pixdevsapps.Stet.flatpakref

Updates then come with flatpak update, or from GNOME Software or KDE Discover. The repository on its own: stet.flatpakrepo; the file the line above fetches is here too.
